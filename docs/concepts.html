Control plane, catalog, and Golden Path

On this page

  • Control plane
  • Catalog
  • Golden Path

This guide uses three terms often: control plane, catalog, and Golden Path. This page defines each one, so you can read the rest of the guide without guessing what they mean.

Control plane

The control plane is the server that receives your joomiz.yaml file and acts on it.

When you run joomiz register, joomiz validate, joomiz plan, or joomiz apply, the CLI sends your file to the control plane. The control plane checks the file against its rules, stores your application's registration, and turns an approved plan into real infrastructure. See How you use this file for what each command sends it.

You don't run or manage the control plane yourself. Your platform team does.

Catalog

The control plane keeps a catalog of the type values you can use in joomiz.yaml.

Every tooling, artifacts, targets, deployments, managed-resources, and consumed-resources entry has a type field. Each type value you write must match an entry the catalog has registered. A catalog entry defines two things for its type:

  • What fields the entry's spec must have.
  • What fields a provisioner can report back in the entry's outputs, if it reports any at all.

Your platform team adds or changes a catalog entry by releasing a new version of the control plane. An entry is a database migration, and no API call writes it. Every installation can have a different catalog, so this guide doesn't try to list every valid type value — see Which tool and resource types can you use? for how to check the current list.

Golden Path

A Golden Path is the name of a supported way to build a service on Joomiz. Your platform team decides which names exist. Today the name is a label. The control plane checks it against its list, and it does not yet use the name to set defaults or to choose tools.

You pick your service's Golden Path in the golden-path field of joomiz.yaml — see The application block. As of this writing, two Golden Paths are available: java-web-application and kotlin-web-application. The control plane rejects any other value.
