For feature teams. This page answers the questions that people ask most often.

Is Joomiz like other infrastructure tools?

Joomiz uses the same idea of a file, a plan and an apply. The differences are in who offers what:

  • You do not choose the providers. Your platform team offers the types that you can request, and it runs the provisioners behind them.
  • Your file describes your application. It does not describe the platform.
  • Joomiz keeps the applied state in the control plane. You keep no state file.

What Joomiz is explains the idea.

Where do secrets go?

A secret never goes in joomiz.yaml. A resource that has a secret reports the address of the secret in a vault. You point at that address with a reference, and your application reads the secret from the vault. Use outputs and secrets shows the flow.

Why does register answer 409?

The application is registered already. A register for an id that Joomiz knows is refused:

error: the control plane rejected joomiz.yaml (HTTP 409)
  Application already registered
  application '48908c60-5a6c-45fe-b5e4-88357f8e78c4' is already registered

Go on with joomiz validate. You register an application once.

Why is my type unknown?

The message unknown ... type means that the platform does not offer the type with that name in that category. Check the spelling, and check that you wrote the type in the right list. The types you can request shows how to see the types of your platform. If the type is not in the list, ask your platform team.

Why does my plan show known after apply?

The value does not exist yet. For example, a database password does not exist until the database exists. Point one value at another explains it.

Why was my apply refused?

Read the message. The most common reasons are another apply that is still running, a plan that is out of date, and a file that was never planned. Make a change shows each one.

Why does a command say that it has no credential?

The CLI has no saved sign-in and no token. Sign in and get access shows how to sign in.

Who can I ask?

Ask your platform team. Fix an error lists what to send with your question.
