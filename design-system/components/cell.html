Cell

The content of one table cell: plain text, code, bold text, a link or a date, with an optional line of small text under it. The data table uses it for every cell.

Inputs

Inputs of the cell component
Input Type Required Default Description
cell object Yes None The cell to show.
Fields of "cell"
Field Type Required Description
text string Yes The text of the cell.
kind string No How to show the text. Without a kind the text is plain.
One of: "code", "strong", "link", "time"
href string No Where the link goes. It is used when the kind is "link".
datetime string No The date in a form that a machine reads, such as "2026-10-14". It is used when the kind is "time".
sub string No A line of small text under the cell.

Source

The template is src/components/cell.html.
