Cell

The content of one table cell: plain text, code, bold text, a link, a date or a status badge, with an optional line of small text under it. The data table uses it for every cell.

Inputs

Inputs of the cell component
Input Type Required Default Description
cell object Yes None The cell to show.
Fields of "cell"
Field Type Required Description
text string Yes The text of the cell.
kind string No How to show the text. Without a kind the text is plain. The kind "badge" is the status badge component.
One of: "code", "strong", "link", "time", "badge"
href string No Where the link goes. It is used when the kind is "link". It must be relative or start with http:, https: or mailto:, or the build stops.
datetime string No The date in a form that a machine reads, such as "2026-10-14". It is used when the kind is "time".
tone string No The tone of the badge. It is used when the kind is "badge".
One of: "neutral", "info", "success", "warning", "danger"
sub string No A line of small text under the cell.

Source

The template is src/components/cell.html.

{% comment %}

{% endcomment %}
{%- if cell.kind == "code" %}<code>{{ cell.text }}</code>
{%- elsif cell.kind == "strong" %}<strong>{{ cell.text }}</strong>
{%- elsif cell.kind == "link" %}<a href="{{ cell.href }}">{{ cell.text }}</a>
{%- elsif cell.kind == "time" %}<time datetime="{{ cell.datetime }}">{{ cell.text }}</time>
{%- elsif cell.kind == "badge" %}{% assign badge_tone = cell.tone | default: "neutral" %}{% render "status-badge.html", label: cell.text, tone: badge_tone %}
{%- else %}{{ cell.text }}{% endif -%}
{%- if cell.sub %}<br><small>{{ cell.sub }}</small>{% endif -%}
