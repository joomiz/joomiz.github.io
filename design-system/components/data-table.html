Data table

A table that scrolls sideways on a small screen, and that a keyboard user can scroll too. The first column stays in view while the rest scrolls.

Examples

Applications and their last plan

Rendered

Applications and their last plan
Application Owner Environment Last plan
billing-service payments prod 15 Oct 2026
inventory-api supply test 14 Oct 2026
order-service checkout prod 12 Oct 2026

Usage

{% render "data-table.html",
     id: "applications",
     caption: "Applications and their last plan",
     columns: columns,
     rows: rows %}

Inputs

Inputs of the data table component
Input Type Required Default Description
id string Yes None An id that is unique on the page. The id of the caption comes from it, and the table is named by the caption.
caption string Yes None The visible name of the table.
columns list of strings Yes None The names of the columns, in order.
rows list of lists Yes None The rows of the table. A row is a list of cells, one for each column. A cell is an object like the one that the cell component takes.
row_header number No 0 The position of the cell that names the row, counting from 0. The first cell is the default.
Fields of "rows"
Field Type Required Description
text string Yes The text of the cell.
kind string No How to show the text. See the cell component.
One of: "code", "strong", "link", "time", "badge"
href string No Where the link goes, for the kind "link".
datetime string No The date for a machine, for the kind "time".
tone string No The tone of the badge, for the kind "badge".
One of: "neutral", "info", "success", "warning", "danger"
sub string No A line of small text under the cell.

Source

The template is src/components/data-table.html.

{% comment %}
  A table that scrolls on a small screen and that a keyboard user can scroll.
  The inputs, with a description and examples, are in data-table.json. The components pages show them.
{% endcomment %}
{%- if row_header %}{% assign header_at = row_header %}{% else %}{% assign header_at = 0 %}{% endif %}
<div role="region" tabindex="0" aria-labelledby="{{ id }}-caption">
  <table>
    <caption id="{{ id }}-caption">{{ caption }}</caption>
    <thead>
      <tr>
        {%- for column in columns %}
        <th scope="col">{{ column }}</th>
        {%- endfor %}
      </tr>
    </thead>
    <tbody>
      {%- for row in rows %}
      <tr>
        {%- for cell in row %}
        {%- if forloop.index0 == header_at %}
        <th scope="row">{% render "cell.html", cell: cell %}</th>
        {%- else %}
        <td>{% render "cell.html", cell: cell %}</td>
        {%- endif %}
        {%- endfor %}
      </tr>
      {%- endfor %}
    </tbody>
  </table>
</div>
