Nav

A list of links in a navigation landmark, such as the main navigation in a header. The link of the current page is marked. An item can have children, which show in a list under it when the pointer is over it or focus is in it.

Examples

A main navigation

Rendered

  • Applications
  • Provisioners
  • Catalog

Usage

{% render "nav.html",
     label: "Example navigation",
     items: items,
     current: "applications" %}

The data that the usage names

{
  "items": [
    { "key": "applications", "label": "Applications", "href": "#" },
    { "key": "provisioners", "label": "Provisioners", "href": "#" },
    { "key": "catalog", "label": "Catalog", "href": "#" }
  ]
}
The HTML that the component writes 
<nav aria-label="Example navigation" data-variant="bar">
  <ul>
    <li><a href="#" aria-current="page">Applications</a></li>
    <li><a href="#">Provisioners</a></li>
    <li><a href="#">Catalog</a></li>
  </ul>
</nav>

Inputs

Inputs of the nav component
Input Type Required Default Description
label string Yes None The accessible name of the navigation. A page with more than one navigation needs a different name for each.
items list of objects Yes None The links, in order.
current string No None The key of the current page. The link with this key is marked with aria-current.
Fields of "items"
Field Type Required Description
key string Yes A name for the link. It is compared with the input "current".
label string Yes The text of the link, or of the button that opens the children.
href string No Where the link goes. An item with children has no href: it is a button.
children list of objects No The links that show under this item. Each child has the three fields below, and cannot have children of its own.
children.key string Yes A name for the child link. It is compared with the input "current".
children.label string Yes The text of the child link.
children.href string Yes Where the child link goes.

Source

The template is src/components/nav.html.

{% comment %}
  A list of links in a <nav>. An item can have children, which show in a list under it.
  The inputs, with a description and examples, are in nav.json. The components pages show them.
{% endcomment %}
<nav aria-label="{{ label }}" data-variant="bar">
  <ul>
    {%- for item in items %}
    {%- if item.children %}
    <li data-submenu>
      <button type="button" aria-expanded="false">{{ item.label }} {% icon "chevron-down" %}</button>
      <ul>
        {%- for child in item.children %}
        <li><a href="{{ child.href }}"{% if child.key == current %} aria-current="page"{% endif %}>{{ child.label }}</a></li>
        {%- endfor %}
      </ul>
    </li>
    {%- else %}
    <li><a href="{{ item.href }}"{% if item.key == current %} aria-current="page"{% endif %}>{{ item.label }}</a></li>
    {%- endif %}
    {%- endfor %}
  </ul>
</nav>
