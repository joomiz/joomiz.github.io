Menu

The groups of a left menu: a heading and a list of links for each group. The link of the current page is marked.

Usage

{% render "menu.html", groups: groups, current: "plans" %}

The HTML that the component writes 
<div data-variant="menu">
    <h2>Inventory-api</h2>
    <ul>
      <li><a href="#">Overview</a></li>
      <li><a href="#" aria-current="page">Last plan</a></li>
      <li><a href="#">Resources</a></li>
    </ul>
    <h2>Configuration</h2>
    <ul>
      <li><a href="#">Environments</a></li>
      <li><a href="#">Tooling</a></li>
    </ul>
</div>

Inputs

Inputs of the menu component
Input Type Required Default Description
groups list of objects Yes None The groups, in order.
current string No None The key of the current page. The link with this key is marked with aria-current.
Fields of "groups"
Field Type Required Description
title string Yes The heading of the group.
items list of objects Yes The links of the group, in order. Each link has the three fields below.
items.key string Yes A name for the link. It is compared with the input "current".
items.label string Yes The text of the link.
items.href string Yes Where the link goes.

Source

The template is src/components/menu.html.

{% comment %}

<div data-variant="menu">
{%- for group in groups %}
    <h2>{{ group.title }}</h2>
    <ul>
      {%- for item in group.items %}
      <li><a href="{{ item.href }}"{% if item.key == current %} aria-current="page"{% endif %}>{{ item.label }}</a></li>
      {%- endfor %}
    </ul>
{%- endfor %}
</div>
