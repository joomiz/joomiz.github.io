Page head

The title of a page, with a one-line lead under it.

Examples

A title and a lead

Rendered

Applications

You see the applications of your own teams. An operator sees all of them.

Usage

{% render "page-head.html",
     title: "Applications",
     lead: "You see the applications of your own teams. An operator sees all of them." %}
The HTML that the component writes 
<hgroup>
  <h1>Applications</h1>
  <p>You see the applications of your own teams. An operator sees all of them.</p>
</hgroup>

Inputs

Inputs of the page head component
Input Type Required Default Description
title string Yes None The title of the page. It is the level 1 heading, so a page has one.
lead string Yes None One line that says what the page is for.
id string No None An id for the heading group, so that a link can point to it.

Source

The template is src/components/page-head.html.
