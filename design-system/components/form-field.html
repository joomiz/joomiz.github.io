Form field

A label, a control, a hint and an error message, linked with for, aria-describedby and aria-invalid. The control is a native input, select or textarea. The error message is always in the markup and stays hidden until it has text, so a script that checks the form only sets the text and aria-invalid.

Examples

A text field with a hint

Rendered

Letters, digits and hyphens. At most 255 characters.

Usage

{% render "form-field.html",
     id: "name",
     label: "Name",
     required: true,
     hint: "Letters, digits and hyphens. At most 255 characters.",
     maxlength: 255,
     autocomplete: "off" %}
The HTML that the component writes 
<div data-variant="field">
  <label for="name">Name <span data-required aria-hidden="true">*</span></label>
  <input id="name" name="name" type="text" maxlength="255" autocomplete="off" required aria-describedby="name-hint name-error">
  <p id="name-hint" data-variant="hint">Letters, digits and hyphens. At most 255 characters.</p>
  <p id="name-error" data-variant="error" hidden></p>
</div>

</div>

A select

Rendered

Usage

{% render "form-field.html",
     id: "kind",
     label: "Kind",
     type: "select",
     options: options %}

The data that the usage names

{
  "options": [
    {
      "value": "managed-resource",
      "label": "Managed resource",
      "selected": true
    },
    { "value": "deployment", "label": "Deployment" }
  ]
}
The HTML that the component writes 
<div data-variant="field">
  <label for="kind">Kind</label>
  <select id="kind" name="kind" aria-describedby="kind-error">
    <option value="managed-resource" selected>Managed resource</option>
    <option value="deployment">Deployment</option>
  </select>
  <p id="kind-error" data-variant="error" hidden></p>
</div>

Inputs

Inputs of the form field component
Input Type Required Default Description
id string Yes None The id of the control. It is unique on the page. The ids of the hint and the error come from it: <id>-hint and <id>-error.
label string Yes None The visible name of the field. A control always has a visible label.
name string No None The name of the control in a form. Without it the id is the name.
type string No text The kind of control. The values "textarea" and "select" make those elements. The others are the type of an input.
One of: "text", "url", "email", "number", "search", "date", "datetime-local", "textarea", "select"
value string No None The value that the control starts with. It is not used for a select: mark an option as selected.
hint string No None A help text under the control. The control names it in aria-describedby.
error string No None An error text. The field then shows it, and the control has aria-invalid="true". Leave it out when there is no error.
required boolean No None Marks the control as required, and the label with an asterisk that a screen reader does not read.
maxlength number No None The most characters that the control takes. It applies to an input and a textarea.
autocomplete string No None The autocomplete value of an input, such as "off".
rows number No 4 The height of a textarea, in rows.
options list of objects No None The options of a select, in order.
Fields of "options"
Field Type Required Description
value string Yes The value that the form sends.
label string Yes The text that the reader sees.
selected boolean No Marks the option that is chosen at the start.

Source

The template is src/components/form-field.html.

{% comment %}
  One form field: a label, a control, a hint and an error message, linked for a screen reader.
  The inputs, with a description and examples, are in form-field.json. The components pages show them.

  The error message is always in the markup, and it is hidden until it has text. A script that checks the form then
  sets its text, shows it, and sets aria-invalid="true" on the control. The control names the error in aria-describedby
  all the time, so the script changes nothing else.
{% endcomment %}
{%- assign kind = type | default: "text" %}
{%- assign described_by = id | append: "-error" %}
{%- if hint %}{% assign described_by = id | append: "-hint " | append: described_by %}{% endif %}
<div data-variant="field">
  <label for="{{ id }}">{{ label }}{% if required %} <span data-required aria-hidden="true">*</span>{% endif %}</label>
  {%- if kind == "select" %}
  <select id="{{ id }}" name="{{ name | default: id }}"{% if required %} required{% endif %}{% if error %} aria-invalid="true"{% endif %} aria-describedby="{{ described_by }}">
    {%- if options %}
    {%- for option in options %}
    <option value="{{ option.value }}"{% if option.selected %} selected{% endif %}>{{ option.label }}</option>
    {%- endfor %}
    {%- endif %}
  </select>
  {%- elsif kind == "textarea" %}
  <textarea id="{{ id }}" name="{{ name | default: id }}" rows="{{ rows | default: 4 }}"{% if maxlength %} maxlength="{{ maxlength }}"{% endif %}{% if required %} required{% endif %}{% if error %} aria-invalid="true"{% endif %} aria-describedby="{{ described_by }}">{{ value | default: "" }}</textarea>
  {%- else %}
  <input id="{{ id }}" name="{{ name | default: id }}" type="{{ kind }}"{% if value %} value="{{ value }}"{% endif %}{% if maxlength %} maxlength="{{ maxlength }}"{% endif %}{% if autocomplete %} autocomplete="{{ autocomplete }}"{% endif %}{% if required %} required{% endif %}{% if error %} aria-invalid="true"{% endif %} aria-describedby="{{ described_by }}">
  {%- endif %}
  {%- if hint %}
  <p id="{{ id }}-hint" data-variant="hint">{{ hint }}</p>
  {%- endif %}
  <p id="{{ id }}-error" data-variant="error"{% unless error %} hidden{% endunless %}>{{ error | default: "" }}</p>
</div>
