Brand

Inputs

Inputs of the brand component
Input Type Required Default Description
label string No None Text beside the logo, such as the name of the tool that the page belongs to. It is part of the name of the link: "Joomiz Design system, home". Without it only the logo shows.
href string No None The page that the logo links to, written from the root of the site, such as "index.html". The component adds the path to the root, so the same value works on every page. Without it the logo links to "#".

Read from the page

The component also reads these values, which every page has. You do not pass them.

root
The path from the page to the root of the site, such as "../". It finds the logo files. Every page has it, so you do not pass it.

Source

The template is src/components/brand.html.
