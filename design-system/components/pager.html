Pager

The links to the previous page and the next page, at the end of a page that belongs to a series, such as a guide. Each link shows the title of its page. The first page has only Next, and the last page has only Previous.

Inputs

Inputs of the pager component
Input Type Required Default Description
previous object No None The page before this one. Leave it out on the first page.
next object No None The page after this one. Leave it out on the last page.
label string No Pages The name of the navigation, for a screen reader. Use a more exact name when a page has more than one series.
Fields of "previous"
Field Type Required Description
title string Yes The title of the page. It is the text of the link.
href string Yes The address of the page, written from this page.
Fields of "next"
Field Type Required Description
title string Yes The title of the page. It is the text of the link.
href string Yes The address of the page, written from this page.

Source

The template is src/components/pager.html.

{% comment %}
  The links to the page before and the page after, at the end of a page of a series.
  The inputs, with a description and examples, are in pager.json. The components pages show them.
{% endcomment %}
<nav aria-label="{{ label | default: 'Pages' }}" data-variant="pager">
  {%- if previous %}
  <a rel="prev" href="{{ previous.href }}">
    <small>Previous</small>
    <span>{% icon "chevron-left" %}{{ previous.title }}</span>
  </a>
  {%- endif %}
  {%- if next %}
  <a rel="next" href="{{ next.href }}">
    <small>Next</small>
    <span>{{ next.title }}{% icon "chevron-right" %}</span>
  </a>
  {%- endif %}
</nav>
