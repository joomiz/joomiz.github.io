Note

A short message that stands out from the text around it, in one of four tones. It takes a body, which you write between the component tags.

Examples

Info

Rendered

Info. Drift detection is off for this environment.

Usage

{% component "note.html", variant: "info" %}
  <p><strong>Info.</strong> Drift detection is off for this environment.</p>
{% endcomponent %}
The HTML that the component writes 
<aside data-variant="info">
  <p><strong>Info.</strong> Drift detection is off for this environment.</p>
</aside>

A message in a live region

Rendered

Saved. The provisioner was registered.

Usage

{% endcomponent %}
The HTML that the component writes 
<aside data-variant="success" role="status">
  <p><strong>Saved.</strong> The provisioner was registered.</p>
</aside>

Inputs

Inputs of the note component
Input Type Required Default Description
variant string Yes None The tone of the note. Each note should start with a word that says the tone, because a colour alone is not enough.
One of: "info", "success", "warning", "danger"
role string No None Makes the note a live region. Use "status" for a message that tells the result of an action, and "alert" for an error that the reader must know at once. A screen reader says the text of a live region when a script puts it there. Without a role the note is plain text. A message should stay until the reader closes it, because a message that goes by itself fails WCAG 2.2.1.
One of: "status", "alert"
children html Yes None The body of the note. Write it between the component and endcomponent tags. It is trusted markup, so escape any text that a reader typed.

Source

The template is src/components/note.html.
