List pager

The controls under a list that a script loads. Mode "more" is for a list that has a cursor: a "Load more" button and a text such as "Showing 100". Mode "pages" is for a numbered list: Previous and Next buttons and a text such as "Page 2 of 7". The text is a status region. A button that is disabled cannot keep focus, so a script that disables the button with focus moves focus to the list or to the other button.

Rendered

Usage

{% render "list-pager.html", mode: "more", summary: "Showing 100 runs" %}
The HTML that the component writes 
<div data-variant="list-pager" data-mode="more">
  <p role="status" data-slot="summary">Showing 100 runs</p>
  <div data-slot="actions">
    <button type="button" data-action="more">Load more</button>
  </div>
</div>

Inputs

Inputs of the list pager component
Input Type Required Default Description
mode string Yes None The kind of list. "more" has a Load more button. "pages" has Previous and Next buttons.
One of: "more", "pages"
summary string Yes None How much is shown, in words, such as "Showing 100 runs" or "Page 2 of 7". A script changes it with textContent.
label string No Pages The name of the navigation, for mode "pages". It tells a screen reader which list the buttons are for.
more_label string No Load more The text of the button of mode "more".
done boolean No None For mode "more": there is nothing more to load, so the button is hidden.
previous_label string No Previous The text of the first button of mode "pages".
next_label string No Next The text of the second button of mode "pages".
first boolean No None For mode "pages": this is the first page, so the Previous button is disabled.
last boolean No None For mode "pages": this is the last page, so the Next button is disabled.

Source

The template is src/components/list-pager.html.

{% comment %}
  How much of a list is shown, and the buttons to get more of it or to move to another page.
  The inputs, with a description and examples, are in list-pager.json. The components pages show them.

  The pager component is for a series of pages of a document, and these are for a list that a script loads. The buttons are
  buttons, not links, because they load data and the address does not change. The summary is a status region, so a screen
  reader says "Showing 100" when a script changes it.
{% endcomment %}
