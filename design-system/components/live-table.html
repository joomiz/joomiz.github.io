Live table

A table that a script fills. It looks and scrolls like the data table, but its body is empty and one row is in a template. The script clones the template for each record, so the markup of a cell comes from the build and only text comes from the script.

Usage

{% render "live-table.html", id: "runs", caption: "Runs", columns: columns, row: row %}

The data that the usage names

{
  "columns": ["Run", "Application", "Status", "Started"],
  "row": [
    { "text": "", "kind": "code" },
    { "text": "", "kind": "strong" },
    { "text": "", "kind": "badge" },
    { "text": "", "kind": "time", "datetime": "" }
  ]
}
The HTML that the component writes 
<div role="region" tabindex="0" aria-labelledby="runs-caption">
  <table>
    <caption id="runs-caption">Runs</caption>
    <thead>
      <tr>
        <th scope="col">Run</th>
        <th scope="col">Application</th>
        <th scope="col">Status</th>
        <th scope="col">Started</th>
      </tr>
    </thead>
    <tbody data-live></tbody>
    <template data-row>
      <tr>
        <th scope="row" data-column="0"><code></code></th>
        <td data-column="1"><strong></strong></td>
        <td data-column="2">
<span data-variant="badge" data-tone="neutral"></span>
</td>
        <td data-column="3"><time datetime=""></time></td>
      </tr>
    </template>
  </table>
</div>

Inputs

Inputs of the live table component
Input Type Required Default Description
id string Yes None An id that is unique on the page. The id of the caption comes from it, and the table is named by the caption.
caption string Yes None The visible name of the table.
columns list of strings Yes None The names of the columns, in order.
row list of objects Yes None The shape of one row: a list of cells, one for each column. The kind of a cell says what the script puts in it. Give each cell an empty text: the script sets the real one. A list with no cell stops the build.
row_header number No 0 The position of the cell that names the row, counting from 0. The first cell is the default.
Fields of "row"
Field Type Required Description
kind string No What the cell holds: the element that the script fills. See the cell component. A cell without a kind holds plain text.
One of: "code", "strong", "link", "time", "badge"
text string Yes The text that the template holds. Give an empty text: the script sets the real one. The cell component needs the field, so it cannot be left out.
href string No Not used. The script sets the address of a link. Leave it empty.
datetime string No Not used. The script sets the date of a time element. Leave it empty.
tone string No The tone that a badge has before the script sets one, for the kind "badge".
One of: "neutral", "info", "success", "warning", "danger"

Source

The template is src/components/live-table.html.

{% comment %}
  A table that a script fills. It is a data table with an empty tbody and one <template> row.
  The inputs, with a description and examples, are in live-table.json. The components pages show them.

  A script finds the body with [data-live], clones the <template data-row> for each record, and sets the text of the element in
  each cell with textContent. data-column holds the position of a cell. The `row` input gives the shape of the row: the kind of
  each cell says what the cell holds, and its text stays empty. The wrapper, the caption and the head are those of data-table.
  The scroll region and the sticky row header are styled by element in css/elements.css, so a live table needs no style of its own.
{% endcomment %}
{%- if row_header %}{% assign header_at = row_header %}{% else %}{% assign header_at = 0 %}{% endif %}
{%- comment %}
  A row with no cell would give a template that a script cannot fill. Reading its first cell stops the build when there is none,
  and the message ("undefined variable: row.first") names the input. The capture throws the value away.
{% endcomment %}

<div role="region" tabindex="0" aria-labelledby="{{ id }}-caption">
  <table>
    <caption id="{{ id }}-caption">{{ caption }}</caption>
    <thead>
      <tr>
        {%- for column in columns %}
        <th scope="col">{{ column }}</th>
        {%- endfor %}
      </tr>
    </thead>
    <tbody data-live></tbody>
    <template data-row>
      <tr>
        {%- for cell in row %}
        {%- if forloop.index0 == header_at %}
        <th scope="row" data-column="{{ forloop.index0 }}">{% render "cell.html", cell: cell %}</th>
        {%- else %}
        <td data-column="{{ forloop.index0 }}">{% render "cell.html", cell: cell %}</td>
        {%- endif %}
        {%- endfor %}
      </tr>
    </template>
  </table>
</div>
