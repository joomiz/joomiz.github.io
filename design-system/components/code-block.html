Code block

Lines of code or command output, in a preformatted block. Every line is escaped, so text such as <b> shows as text.

Examples

The output of a plan

Rendered

$ joomiz plan
Plan for inventory-api in environment test
  + managed-resource/postgres  inventory-api-db  (create)
  ~ deployment/jar             inventory-api     (update)
Nothing is written. Run joomiz apply to make these changes.

Usage

{% render "code-block.html", lines: lines %}

The data that the usage names

{
  "lines": [
    "$ joomiz plan",
    "Plan for inventory-api in environment test",
    "  + managed-resource/postgres  inventory-api-db  (create)",
    "  ~ deployment/jar             inventory-api     (update)",
    "Nothing is written. Run joomiz apply to make these changes."
  ]
}
The HTML that the component writes 
<pre><code>$ joomiz plan

</code></pre>

Inputs

Inputs of the code block component
Input Type Required Default Description
lines list of strings Yes None The lines to show, in order. Each string is one line.

Source

The template is src/components/code-block.html.
