State panel

What a block of a screen shows when it has no data: an empty list, a wait, or a failure. It has a title, an optional text and an optional action, such as "Try again". The loading state sets aria-busy="true" and is a status region. The error state is an alert. The title says which state it is, so colour is never the only signal.

Usage

{% render "state-panel.html",
     state: "empty",
     title: "No provisioners yet",
     text: "Register a provisioner so that plan and apply can reach a type.",
     action_label: "Register a provisioner",
     action_href: "#" %}
The HTML that the component writes 
<div data-variant="state-panel" data-state="empty">
  <p data-slot="title">No provisioners yet</p>
  <p data-slot="text">Register a provisioner so that plan and apply can reach a type.</p>
  <a href="#" data-slot="action">Register a provisioner</a>
</div>

Usage

{% render "state-panel.html",
     state: "error",
     title: "The runs could not be loaded",
     text: "Try again in a moment.",
     action_label: "Try again" %}
The HTML that the component writes 
<div data-variant="state-panel" data-state="error" role="alert">
  <p data-slot="title">The runs could not be loaded</p>
  <p data-slot="text">Try again in a moment.</p>
  <button type="button" data-slot="action">Try again</button>
</div>

Inputs

Inputs of the state panel component
Input Type Required Default Description
state string Yes None Which state to show. It sets data-state, and for "loading" and "error" the role as well.
One of: "empty", "loading", "error"
title string Yes None A short title that says the state in words, such as "No provisioners yet", "Loading runs" or "The runs could not be loaded".
text string No None One or two sentences that say what the reader can do.
action_label string No None The text of the action. Without it the panel has no action.
action_href string No None Makes the action a link to this address. It must be relative or start with http:, https: or mailto:, or the build stops. Without it the action is a button, which a script gives a click handler.

Source

The template is src/components/state-panel.html.

{% comment %}
  An empty, a loading or an error state of a block of a screen, with a title, a text and an optional action.
  The inputs, with a description and examples, are in state-panel.json. The components pages show them.

  Loading is a status region with aria-busy. An error is an alert, so a screen reader says it at once. An empty state is
  plain text: nothing changed, so nothing needs to be said. A script that changes `data-state` on a panel that it keeps must
  change role and aria-busy to match.
{% endcomment %}
<div data-variant="state-panel" data-state="{{ state }}"
  {%- if state == "loading" %} role="status" aria-busy="true"
  {%- elsif state == "error" %} role="alert"
  {%- endif %}>
  <p data-slot="title">{{ title }}</p>
  {%- if text %}
  <p data-slot="text">{{ text }}</p>
  {%- endif %}
  {%- if action_label %}
  {%- if action_href %}
  <a href="{{ action_href }}" data-slot="action">{{ action_label }}</a>
  {%- else %}
  <button type="button" data-slot="action">{{ action_label }}</button>
  {%- endif %}
  {%- endif %}
</div>
