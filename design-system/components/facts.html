Facts

Facts about one thing, as a description list: a label and a value for each fact.

Examples

One application

Rendered

Golden path
kotlin-web-application
Owner
supply
Repository
github.com/joomiz/inventory-api

Usage

{% render "facts.html", items: items %}

The data that the usage names

{
  "items": [
    {
      "label": "Golden path",
      "value": "kotlin-web-application",
      "kind": "code"
    },
    { "label": "Owner", "value": "supply" },
    {
      "label": "Repository",
      "value": "github.com/joomiz/inventory-api",
      "kind": "link",
      "href": "#"
    }
  ]
}
The HTML that the component writes 
<dl class="facts">
  <dt>Golden path</dt>
  <dd><code>kotlin-web-application</code></dd>
  <dt>Owner</dt>
  <dd>supply</dd>
  <dt>Repository</dt>
  <dd><a href="#">github.com/joomiz/inventory-api</a></dd>
</dl>

Inputs

Inputs of the facts component
Input Type Required Default Description
items list of objects Yes None The facts, in order.
Fields of "items"
Field Type Required Description
label string Yes The name of the fact.
value string Yes The value of the fact.
kind string No How to show the value. Without a kind the value is plain text.
One of: "code", "link"
href string No Where the link goes, for the kind "link".

Source

The template is src/components/facts.html.

{% comment %}
  Facts about one thing, as a description list.
  The inputs, with a description and examples, are in facts.json. The components pages show them.
{% endcomment %}
<dl class="facts">
  {%- for item in items %}
  <dt>{{ item.label }}</dt>
  <dd>
    {%- if item.kind == "code" %}<code>{{ item.value }}</code>
    {%- elsif item.kind == "link" %}<a href="{{ item.href }}">{{ item.value }}</a>
    {%- else %}{{ item.value }}{% endif -%}
  </dd>
  {%- endfor %}
</dl>
