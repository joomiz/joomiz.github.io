Joomiz design system

Plain CSS for native HTML, with light and dark themes. A page loads three style sheets and needs no class for an element. The levels below go from the smallest part to a whole page.

The five levels of the design system
Level What it is Where
Tokens Named values: colour, space, type, motion. css/tokens.css, css/theme.css
Elements A native HTML element, styled by the CSS. It has no template and takes no input. css/elements.css
Components A template with inputs and a spec. It fixes a structure that pages repeat. src/components/
Patterns Components combined for one task, such as a list page. Not built yet
Layouts A page shell with slots for a header, a menu and the content. Each can be previewed in a desktop and a mobile frame. src/layouts/

The reasons for the names are in the design system's decision records. To see a layout on a screen the size of a phone, open it from the Layouts page.
